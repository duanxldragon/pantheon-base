# Task Packet: 2026-10-21-v0170-release-cut

## Goal

把 v0.16.1 之后合入 main 的 13 个提交（租户隔离整改 #386、#391–#394，依赖升级 #381/#384/#385，
发布管线修复 #383/#387–#390）打包为一次 **minor** foundation release（v0.17.0），并发布四件可消费
产物，使 `pantheon-ops` 能把锁从 v0.16.1 推进到包含这些安全修复的版本。

platform

## Implementation Notes

- 版本判定：`docs/VERSION_MANAGEMENT_GUIDE.md` §2.3 的 minor 覆盖「功能增强 / 行为变更」。本次包含
  租户隔离的行为变更（跨租户策略写入改为 `TENANT_FORBIDDEN`）、新增迁移 `000025`–`000028`，以及
  平台命名空间角色键的拒绝规则；`.harness/STATUS.md` 亦已记录租户整改随 v0.17.0 minor 发布。
- `sharedPaths` 保持不变（backend 4、frontend 46、docs 2），消费仓只需移动版本、commit 与校验和。
- 迁移全部为 additive；`000028` 带 down migration。
- 发布物必须齐备四件：`foundation-release-pantheon-base-v0.17.0.tgz`、其 `.sha256`、`repo.tar`、
  `repo.tar.sha256`；`Foundation Release Verify` 会在 `release: published` 上断言。
- 发布使用维护者凭据在本地执行 canonical 脚本（仓库 `default_workflow_permissions=read`，CI 无法
  创建 Release；该限制已在 v0.16.1 证据中记录）。
