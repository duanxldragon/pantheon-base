# Pantheon Base v0.10.0 Release Candidate

## Scope

- Prepare `pantheon-base-v0.10.0` from the current Base main line.
- Repair release tooling, candidate-bound gates, smoke reliability, and release evidence.
- Keep product capability frozen except for defects that directly block trustworthy release validation.

## Out Of Scope

- Any modification in `pantheon-ops`.
- New Base features or consumer overlay work.
- Creating the release tag or publishing the GitHub Release before maintainer approval.

## Success Criteria

- Release tooling accepts only `pantheon-base-vX.Y.Z` with a matching `release/X.Y` line.
- The bundle is reproducible on Windows and contains no stale prior output.
- Release Gate validates all required checks on the exact candidate SHA and fails closed on API errors.
- Focused cleanup smoke is stable across month boundaries and cleanup failures cannot report success.
- Local gates, independent review, hosted required checks, and Full Smoke are green.
- Ignored release metadata and assets bind to the accepted candidate SHA.
