# Activity writer repair: verified executor handoff

The narrow Base `system/auth` safety repair is implemented and locally verified. This is executor evidence, not independent approval of the tenant plan or release.

## Changes

- `backend/pkg/authtoken/token.go`: replace TTL/default-TTL/unconditional SET with identity validation and atomic Lua GET/PTTL/raw-value comparison/SET XX KEEPTTL. Missing/expired keys return ErrNotFound; persistent/invalid/mismatched/nil data/context return ErrInvalid; nil store returns ErrStoreNotInitialized; cancellation and Redis errors propagate. No access token issuance fallback or expiration extension.
- `backend/pkg/authtoken/token_activity_test.go`: six focused top-level regressions covering stale reads, no TTL/invalid payload, exact uint64 and role/tenant identities, millisecond expiration, nil/canceled/store failures, and deterministic read/write interleavings.
- `backend/internal/middleware/token_activity_regression_test.go`: legacy resolve/cache/activity interleaving followed by independent ValidateSession checks; invalidated key stays absent, cache activity stays unchanged, provider-like entry/release continuations stay zero.

No exported signature, route/cache default, issuance helper, schema/index, legacy authorization policy, dependency, ledger, lock, baseline, release or remote state change. Existing unrelated edits were preserved.
